# Time Slot Engine Skill

Цей скіл описує алгоритмічні правила для підбору оптимальних часових вікон у Bagira Planner.

## Основні Правила та Розрахунки:
1. **Загальний часовий інтервал**: $T_{\text{total}} = \sum (T_{\text{тривалість}} + T_{\text{буфер}})$.
2. **Фільтрація Майстрів**: Вибір лише тих майстрів, що мають кваліфікацію для обраних послуг.
3. **Оптимальність (Adjacency Bonus)**: Найвищий пріоритет віддається вікнам, що слідують одразу після існуючого запису або на початку зміни (запобігання простою).
4. **Мульти-майстрові послідовні записи**: Якщо один майстер не може виконати всі послуги підряд, алгоритм формує послідовну чергу (Майстер А $\rightarrow$ Майстер Б).
